DM 캠페인 이전 — 99% 복원 설계

3차 연구. "시간이 걸려도 거의 전부 복원" 요구에 대한 타당성 검증 + 설계.

2026-08-13 · prod 읽기 전용(GET) 실측 · 대상 계정 3곳 · 게시물 32개 스윕

결론

99%는 도달 가능합니다. 단 "표본 추출"을 버리고 "적응형 전수 조사 + 시간창 정확 조인"으로 바꿔야 하고,
가장 중요한 건 — 우리는 그걸 측정으로 증명할 수 있습니다.

정답지가 있습니다. 우리 SentDMLog 53,228건 · IG 연결 30개. "누구에게 무슨 문구를 언제 보냈는지" 다 압니다. 복원기를 우리 계정에 돌려 실제 회수율을 계산하면 99%가 희망이 아니라 숫자가 됩니다.

1. 먼저 — 무엇의 99%인가

정의를 고정합니다. "모든 DM을 한 통도 빠짐없이"는 불필요하고 불가능합니다. 캠페인 문구는 모두에게 동일하므로 게시물당 5~10건만 건지면 내용은 완전히 복원됩니다.

따라서 목표는 "캠페인이 돌았던 게시물 중 99%에서 실제 발송 문구·키워드·구조를 복원" 입니다. 분모는 DM이 1건 이상 실제 전달된 게시물. 전달이 0건인 게시물은 물리적으로 원본이 없으므로 별도 취급(§7)합니다.

2. 측정된 사실 — 관문 2개는 통과했다

통과 관문 A — IG 대화 보존 기간은 문제가 아니다

가장 큰 우려였습니다. "오래된 캠페인은 대화가 사라졌을 것".

IG 대화는 사실상 무기한 보존됩니다. 11개월 전 발송 DM이 본문·버튼·URL 그대로 나왔습니다. → 오래된 캠페인도 복원 대상입니다.

통과 관문 B — "댓글러 5명 찔러보기"가 분류기를 대체한다

지금 파이프라인은 LLM이 "캠페인 같다"고 판정한 게시물만 DM 복원을 시도합니다. 분류기가 틀리면 그 게시물은 영구히 누락됩니다 — 99%의 최대 적입니다.

이제 조회 1건이 ~1.2초에 적중률이 높으므로, 판정하지 말고 그냥 찔러보면 됩니다. DM이 있으면 캠페인, 없으면 아님. 추론이 관측으로 대체됩니다.

실측: 게시물당 댓글러 5명만 조회한 결과 —

5/5 적중 (완전)18개
1~4/5 적중 (부분)7개
0/5 (미적중)7개

게시물 32개 중 25개(78%)가 5명만으로 즉시 복원. 나머지 7개가 §3의 과제입니다.

증거: 표본을 키우면 바이럴도 나온다. 2차 연구에서 같은 급의 바이럴 게시물(댓글 1,138~4,935)에 댓글러 12~24명을 조회하자 게시물당 23~116건이 복원됐습니다. 5명에서 24명으로 늘린 것만으로 0 → 314건.

즉 바이럴 게시물은 불가능한 게 아니라 비싼 것입니다. 그리고 "시간이 걸려도 된다"면 비싼 건 문제가 아닙니다.

필요 표본 수 — 확률 계산

댓글러 1명당 적중 확률 p 일 때, 99% 확신으로 최소 1건을 건지려면 log(0.01)/log(1-p) 명이 필요합니다.

4. 99% 설계 — 6단계

필수전 게시물 열거 (분류 게이트 제거) 미디어를 끝까지 페이징(50/콜, 100개당 2콜). media_limit 잘라내기 폐지 — 캠페인은 1년 전 게시물에도 있다(@manjzangi 2025-10 확인). LLM 분류를 "복원 시도 여부"의 게이트로 쓰지 않는다(분류는 라벨링으로만 강등).
핵심얕은 스윕 — 전 게시물 × 댓글러 5명 댓글 있는 모든 게시물에 5명씩 찔러본다. 실측 78%가 여기서 끝난다. DM 유무가 곧 캠페인 판정이므로 분류 오탐/미탐이 회수율에 영향을 못 준다.
핵심적응형 에스컬레이션 — 증거가 있으면 끝까지 0~부분 적중 게시물만 표본을 늘린다. 중단 조건은 "증거 유무": ① 계정 본인 공개답글 존재 ② 댓글 반복률 높음 ③ 캡션 CTA — 하나라도 있으면 캠페인이 돈 물증이므로 p=0.05 가정치(90명)까지 파고, 셋 다 없으면 5명에서 종료(캠페인 없음으로 확정). 예산을 의심스러운 곳에만 쓴다.
바이럴 결정타확정 타겟 우선 — 공개답글 parent_id 계정이 단 공개답글의 parent_id = 트리거한 댓글 = 자동화가 확실히 발동한 사람. 적중률이 100%인 일반 게시물에선 이득이 없지만(97%→100%), 적중률이 10~20%로 떨어지는 바이럴에서 표본 효율을 몇 배로 올린다. 첫 50댓글만으로도 확정 타겟 491명이 나왔다(실측).
버그 수정7일 시간창 정확 귀속 현재 fetch_targeted_dms 는 그 사람에게 보낸 모든 발신 DM을 가져온다 — 시간창이 없다. 실측에서 2026-05 게시물에 2025-09 DM이 딸려왔다(무관한 과거 대화). Meta 규칙상 Private Reply 는 댓글 후 7일 내만 가능하므로 댓글시각 ≤ DM시각 ≤ 댓글시각+7일 로 자르면 귀속이 확정된다. 한 사람이 여러 게시물에 댓글을 달았어도 정확히 갈린다.
충실도관측 기반 재구성 — LLM 추측 제거 DM을 받은 사람이 정확히 누구인지 알게 되면, 그들의 댓글 원문도 안다:
· 트리거 키워드 = DM 받은 댓글들의 공통 토큰 (추측 → 관측)
· 오프닝 → 게이트 → 리워드 순서 = 한 대화 내 발신 메시지 시간순
· 후속 딜레이 = 같은 대화 발신 간 시간차
· 버튼 문구·URL = cta[]
지금 LLM이 캡션에서 상상하는 항목들이 전부 관측으로 대체된다.

6. 99%를 측정하는 방법 — 이게 이 계획의 핵심

우리는 정답을 갖고 있습니다. SentDMLog 53,228건 — 게시물별로 누구에게 어떤 문구를 언제 보냈는지, 성공/실패까지.

채점기(scorer)를 만듭니다:

우리 IG 연결 30개 각각에 대해
  1. SentDMLog 에서 정답 구성:  {게시물 → 실제 발송 문구·키워드·수신자 집합}
  2. 복원기를 그 계정에 실행 (SentDMLog 조회 없이, 순수 Graph API 만)
  3. 대조:
     · 게시물 회수율   = 복원한 캠페인 게시물 / 실제 캠페인 게시물
     · 문구 정확도     = 복원 문구가 실제 발송 문구와 일치(지문/유사도)
     · 키워드 정확도   = 복원 키워드 ∩ 실제 keyword_filter
     · 오귀속률        = 다른 게시물 DM 을 잘못 붙인 비율   ← 7일 창 검증

→ "99%"가 주장이 아니라 리포트 숫자가 됩니다. 그리고 이 채점기는 회귀 테스트로 영구히 남습니다 (자기발송 제외 로직을 끄고 돌려야 정답 대조가 성립 — 채점 모드 플래그 필요).

왜 이게 중요한가 — 1차 연구가 "구조적 복원 불가"를 잘못 결론 낸 이유가 정확히 이것입니다. 정답을 모르는 외부 계정에서 시작해 안 나오는 이유를 추론으로 메웠습니다. 같은 실수를 반복하지 않으려면, 정답 있는 데이터로 먼저 채점한 뒤 미지 계정으로 나가야 합니다.

7. 남는 1% — 정직하게

못 살리는 것왜대응
전달이 정말 0건인 게시물 모든 댓글러가 비팔로워 + 채널 미개설(2534025). 실측에서 이 버킷은 대화 반환률 50% — 절반은 진짜로 비어 있다 같은 시기 형제 게시물의 실제 문구를 시간 상관으로 차용 + "추정" 배지
대화가 삭제/차단된 상대계정 탈퇴·차단·대화 삭제표본을 늘리면 다른 수신자로 대체됨
후속 분기 조건(if/then)발신 기록엔 결과만 남고 조건은 안 남는다딜레이·순서까지만 복원, 분기는 사용자 확인
캠페인이 공개답글 없이 돌고 전달도 실패한 경우물증이 하나도 없다 → 에스컬레이션 근거 없음얕은 스윕에서 종료(오탐 방지가 더 중요)

최후의 수단은 계속 유효합니다 — "이 게시물의 DM 문구를 붙여넣으세요" 입력창. 자동 복원이 99%여도 남는 1%는 사용자가 30초면 채웁니다. 이전 기능은 100% 자동일 필요가 없고, 100% 완성되면 됩니다.
