3. 이번에 고친 것 두 가지

3-1. 배타 할당은 폐기했습니다 역효과 확인

"같은 문구가 여러 게시물에 뜨면 지지가 가장 높은 하나에만 배정한다"는 규칙을 넣었습니다. 직전 측정에서 정밀도 97%로 좋아 보였는데, 실계정에 적용하니 @mini_ai_ 42개 중 35개가 '없음'이 됐습니다.

원인: 이 계정은 팔로우 확인 🙌🏻 같은 동일한 게이트 문구를 모든 게시물에서 씁니다. 배타 규칙이 그걸 한 게시물에만 남기고 나머지 34개에서 지워버린 것입니다.

왜 측정이 속였나: 97%는 우리 캠페인을 정답지로 잰 값인데, 우리 캠페인은 게시물마다 문구가 다릅니다. 측정 표본이 현실을 대표하지 못했습니다. → 배타 할당 없이 지지비율만으로도 60%+ 구간 정밀도가 100% 이므로 제거하는 게 맞습니다.

3-2. 게이트와 오퍼를 분리했습니다 URL 3 → 42

"지지비율이 가장 높은 문구 하나"를 캠페인으로 뽑았더니, 나온 것이 전부 팔로우 확인 🙌🏻 였습니다. 오퍼 URL 확보가 42개 중 3개에 그쳤습니다.

이유는 구조에 있습니다 — 게이트 DM은 댓글 단 사람 전원에게 가서 지지 100%, 오퍼 DM(URL 포함)은 팔로우를 실제로 누른 사람에게만 가서 지지가 낮습니다. 최고 지지 하나만 뽑으면 구조적으로 URL 없는 게이트만 나옵니다.

URL 있는 문구와 없는 문구를 각각 최고 지지로 뽑아 한 쌍으로 묶자 오퍼 URL 확보가 3 → 42 (100%) 가 됐습니다. 덤으로 팔로우게이트 유무·문구까지 함께 복원되어 2단 구조가 그대로 재현됩니다.
