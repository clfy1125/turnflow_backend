스크립트 주석에 "공개답글 수는 신호로 쓰지 않는다 — 7차에서 역방향 확인" 이라고 적어놓고, 정작 WEAK 조건에는 공개답글 > 0 을 그대로 남겨뒀습니다. STRONG 에서만 빼고 WEAK 에서 안 뺀 것입니다. 이 계정은 일상 게시물에 답글을 많이 달기 때문에 247개가 WEAK 로 몰렸습니다.

다음 튜닝 (근거 명확)
  1. WEAK 조건에서 공개답글 제거 — 반복률 ≥10% 또는 캡션 CTA 만 남긴다
  2. WEAK 예산 12명 → 4명 — 7차에서 성공 게시물의 47%가 3명 안에 끝났다. 3명에 안 나오면 12명까지 가도 수확이 낮다
  3. 1차 조회 6명 → 3명 복원 — 이번에 6명으로 올린 것이 초반 24% 지연의 주원인

예상 절감 약 25분. 단 WEAK 에서 나온 127건 중 일부를 잃을 수 있어 얼마를 잃는지는 돌려봐야 압니다.

7-6. 판정 등급을 처음 만들었을 때는 완전히 빗나갔습니다 측정

실패 목록을 사람이 보기 좋게 "★강함/중간/약함" 으로 자동 등급을 매겼는데, ★강함으로 뽑힌 4건이 전부 캠페인이 아니었습니다 (파이팅×17 하이스트×4 :)×1 시크릿은 사랑×1 — 전부 개인 스토리 게시물).

반대로 진짜 캠페인 2건은 "중간"으로 분류됐습니다.

원인: 등급에 공개답글 수를 큰 가중치로 넣었는데, 이 계정은 일상 게시물에는 답글을 많이 달고 대형 캠페인에는 안 답니다 — 신호가 정확히 반대였습니다. 올바른 판별식은 「캡션에 트리거 단어 명시 + 높은 댓글 반복률」 하나입니다.

8. 다음에 할 것

  1. 놓친 2건에 100명 조회 20분 — 초대형 게시물의 표본 상한만 올리면 99% → 100%가 되는지 확인. 5차 연구 선례상 가능성이 높다. 성공하면 "댓글 1,000개 이상이면 조회 상한 상향" 규칙 하나로 끝난다
  2. 캠페인 판별식 교체 — 「공개답글 수」를 빼고 「캡션 트리거 명시 + 댓글 반복률」로. §7-4에서 현재 방식이 완전히 빗나갔다. 이 판별식은 실패 게시물을 사용자에게 보여줄지 말지를 결정하므로 중요하다 (147개 일상 게시물을 "복원 실패"로 보여주면 안 된다)
  3. 정답 대조 채점 — 아직 안 했습니다. 지금까지는 "찾았다"까지고, 찾은 문구가 원본과 같은지는 우리 발송 기록 5만 3천 건과 대조해야 나옵니다. 채점 시엔 "우리 캠페인 게시물 제외"를 반대로 켜야 합니다(그게 정답지라서)
  4. 기간 제한 UX 설계 — 최근 2~3년 우선 + "더 찾기". §5의 수확 체감이 근거
  5. 실패 비용 절감 — 실패 게시물이 성공보다 4배 비싸다(12명 vs 3명). §7 에서 실패 대부분이 댓글 50개 미만 일상 게시물로 확인됐으므로, 반복률이 낮으면 3명에서 종료해도 안전하다 → 74분을 크게 줄일 수 있다
