# 게시물이 '연령 제한'에 걸리면 자동 DM이 나가지 않습니다 — 크리에이터 안내

작성 2026-09-07 · 근거: 실서버 21개 게시물 실측 + Meta 공식 정책 + 로그아웃 브라우저 검증 10건

## 1. 무슨 일이 일어나나요

인스타그램이 **게시물 하나를 '연령 제한 콘텐츠'로 분류**하면, 그 게시물에서만 이런 일이 동시에 일어납니다.

```
① 로그인 안 한 사람·10대에게 게시물이 안 보입니다  (도달 하락)
② 그 게시물의 댓글 알림이 자동화 도구에 전달되지 않습니다
③ 그 게시물의 댓글에 자동 DM을 보낼 수 없습니다      ← 여기가 체감되는 증상
```

**계정 문제가 아닙니다.** 같은 계정의 다른 게시물은 같은 시각에 정상 발송됩니다. 실제로 어떤 고객은 하루 차이로 올린 릴스 중 하나만 막히고 다른 하나는 100% 발송됐습니다.

**재연결·권한 재승인으로는 풀리지 않습니다.** 토큰이나 권한 문제가 아니기 때문입니다. 실제로 한 고객이 재연결과 권한 전체 재승인을 했지만 그대로였고, 새 게시물로 캠페인을 만들자 바로 정상 발송됐습니다.

**우리 서비스만의 문제도 아닙니다.** 2026년 9월 4일부터 시작됐고, 다른 자동 DM 도구(NHN 소셜비즈 등)도 같은 날 같은 공지를 냈습니다. 같은 게시물에서 인포크링크도 함께 막힌 사례를 확인했습니다.

## 2. 내 게시물이 제한됐는지 30초 만에 확인하는 법

**시크릿 창(또는 로그아웃 상태)에서 그 게시물 링크를 엽니다.**

| 보이는 화면 | 판정 |
|---|---|
| **"연령 제한 콘텐츠 / 회원님의 연령 또는 계정 설정에 따라 연령이 제한된 콘텐츠입니다."** | 🔴 제한됨. 자동 DM 불가 |
| 영상이 정상 재생됨 | 🟢 정상. 다른 원인을 찾아야 함 |

크롬 기준: `Ctrl+Shift+N`(맥은 `Cmd+Shift+N`) → 주소창에 게시물 링크 붙여넣기.

> 휴대폰 인스타 앱으로는 확인이 안 됩니다. 이미 로그인돼 있어서 그냥 보입니다. **반드시 로그아웃 상태의 웹브라우저**로 확인하세요.

## 3. 제한에 걸리지 않게 쓰는 요령

### 3-1. Meta가 공식적으로 10대에게 가리는 콘텐츠 (확실한 것)

Meta 투명성 센터에 명시된 카테고리입니다. 여기 해당하면 거의 확실히 제한됩니다.

| 카테고리 | 구체적으로 |
|---|---|
| **체중 감량 제품·서비스** | 다이어트 보조제, 효소, 디톡스, 체중 감량 프로그램, "○kg 뺐어요" 식 전후 비교 |
| **극단적 체중 관리 표현** | "굶어서", "폭식", 몸무게 수치 강조, 극단적 감량 서사 |
| 담배·니코틴·주류·총기 판매 | 술 레시피 포함 |
| 향정신성 약물·대마 권장 | |
| **성적으로 암시적인 표현·이미지** | 신체 부위 클로즈업, 노출이 큰 화면, 암시적 문구 |
| **강한 비속어** | 욕설, 비하 표현 |
| 위험한 행동·스턴트 | 높은 곳에서 뛰기 등 |
| 자해·자살·섭식장애 관련 | 회복 서사 제외 |
| 심한 폭력·유혈 | |

### 3-2. 우리 고객 사망 게시물에서 실제로 많이 보인 요소 (관찰)

Meta가 공식 확인해준 건 아니지만, 실측한 제한 게시물에서 반복적으로 나온 것들입니다.

| 위험 요소 | 실제 사례 문구 |
|---|---|
| **미용 시술·병원** | "팔자주름 … 무슨 종류 했는지랑 **병원정보** 보내드릴게요" |
| **다이어트·이너뷰티 제품** | "여리티, **똥빼기**, **효소** 같은 이너뷰티 라인업" |
| **미백·화이트닝** | "**미백크림**", "**화이트닝** 제품", "톤업템" |
| **체형 변화 효과 주장** | "몸 전체가 개운해지면서 **붓기가 싹 빠지더라고요**", "**살 빼고** 입어야지" |
| **비하·비속어** | "**듣보잡** 털어오는 **저급** 창고", "눈 뒤집혀서", "웩(?)" |
| **소득·수익 보장 주장** | "주말에 이거 하면 **연봉 300만 원 올릴 수 있습니다** 💰" |
| 시술성 화장품 성분 | "스피큘" |

### 3-3. 안전하게 바꿔 쓰는 예시

| ❌ 위험 | ✅ 대안 |
|---|---|
| 효소·똥빼기·디톡스로 붓기 싹 빠져요 | 상쾌한 하루를 위한 이너케어 루틴 |
| 미백크림으로 톤업 확실 | 데일리 스킨케어 루틴 소개 |
| 팔자주름 병원정보 드려요 | 홈케어 관리법 정리해 드려요 (병원·시술명은 DM으로만) |
| 살 빼고 입으려던 부츠컷 | 체형별 핏 비교해봤어요 |

### 3-4. ⚠️ 캡션만 고쳐서는 부족합니다 — 실측 결과

**캡션 내용으로는 제한 여부가 갈리지 않았습니다.** 한 고객은 "AI 툴 등급 매겨봤습니다"는 제한됐고, 하루 전에 올린 "AI 툴 정리" 게시물은 정상이었습니다. 문구·해시태그·링크·이벤트 방식이 사실상 같았습니다.

즉 인스타의 분류기는 **영상 자체(화면에 뜨는 자막, 썸네일, 비주얼, 음원)** 도 봅니다. 그래서:

- 썸네일·첫 3초 화면에 위 위험 단어를 **자막으로 크게 박지 마세요** (캡션보다 이게 더 위험할 수 있습니다)
- 노출이 큰 장면, 신체 부위 클로즈업을 피하세요
- 자극적인 효과음·경고음(🚨 사이렌 등)을 과하게 쓰지 마세요

### 3-5. 하나 더 — 자동 DM 도구는 게시물당 하나만

같은 게시물에 우리 것과 다른 도구(인포크링크·매니챗 등)를 **동시에 붙이지 마세요.** 실측한 사례에서 다른 도구가 15시간 동안 대량 발송한 뒤 그 게시물이 죽었고, 그 도구도 함께 막혔습니다. 도구를 바꾸실 때는 **이전 도구를 먼저 끄고** 새 게시물부터 시작하세요.

## 4. 이미 제한에 걸렸다면

| 순서 | 할 일 |
|---|---|
| 1 | **시크릿 창으로 확인** (2장) — 제한이 맞는지 먼저 확정 |
| 2 | **인스타 앱 → 설정 → 계정 상태(Account Status)** 확인. 제한 사유가 표시되면 **검토 요청(이의제기)** 을 넣습니다 |
| 3 | 검토가 통과되면 제한이 풀리고 자동 DM도 함께 살아납니다. **다만 통과 보장은 없고 시간이 걸립니다** |
| 4 | **기다리는 동안은 새 게시물로 캠페인을 다시 만드세요.** 실측상 이게 가장 확실하고 빠릅니다 |
| 5 | 죽은 게시물의 캠페인은 **정지**해 두세요. 켜두면 실패만 쌓이고 같은 사람에게 재시도됩니다 |

**하지 말아야 할 것**
- ❌ 인스타 재연결 / 권한 재승인 — 효과 없습니다 (실측 확인)
- ❌ 같은 게시물에 캠페인을 복사해서 다시 만들기 — 실패만 늘어납니다 (한 고객이 이걸로 42건 추가 실패)
- ❌ 게시물 삭제 후 재업로드 — 같은 영상이면 다시 걸릴 가능성이 높습니다

## 5. 우회 경로 — 댓글이 막혀도 DM은 살아 있습니다

제한은 **"댓글에 답장하는 자동 DM"** 만 막습니다. **"고객이 DM으로 키워드를 보내면 답장하는 자동 DM"** 은 정상 작동합니다.

```
❌ 막힘:  게시물에 댓글 "참여"  →  자동 DM
✅ 됨  :  DM으로 "참여" 전송   →  자동 DM
```

경쟁 도구(NHN 소셜비즈)도 이 방법을 공식 우회책으로 안내하고 있습니다. 제한된 게시물에서는 안내 문구를 이렇게 바꾸면 됩니다.

> "댓글에 **참여** 남겨주세요" → "**DM으로 참여** 보내주세요"

**(사내) 제품 과제** — 우리도 DM 키워드 트리거 경로가 있으면 제한 게시물을 통째로 구제할 수 있습니다. 우선순위 검토 필요.

## 7. (사내) 서버에서 자동 판별하는 법 — 구현 가능합니다

**Graph API 필드로는 안 됩니다.** `is_comment_enabled`·`media_product_type`·`?metadata=1` 전부 정상값이고
제한 여부가 노출되지 않습니다.

**공개 페이지를 크롤러 User-Agent 로 1회 조회하면 판별됩니다.** 토큰 불필요, Graph 쿼터 소모 0.

```bash
UA='Mozilla/5.0 (compatible; Googlebot/2.1; +http://www.google.com/bot.html)'
curl -sL -A "$UA" "https://www.instagram.com/reel/<shortcode>/"   | grep -qF '"title":"Age-restricted content"' && echo RESTRICTED || echo OK
```

제한된 게시물의 응답 JSON 안에 이 블록이 들어 있습니다:
```json
{"description":"This content is age-restricted based on your age or account settings.",
 "title":"Age-restricted content","id":"POLARIS_...","comments_connection":{"edges":[],"page_info":null}}
```
`comments_connection.edges` 가 **빈 배열**인 것도 같이 보입니다 — 댓글이 아예 안 실립니다.

### 7-1. 검증 결과 — 25건 전수, 오탐·미탐 0

| 그룹 | n | 판정 | 응답 크기 |
|---|---:|---|---|
| 자동 DM 사망 게시물 | 13 | **전부 RESTRICTED** | 699~709 KB |
| 정상 게시물 (무캠페인 포함) | 12 | **전부 OK** | 930~952 KB |

**응답 크기만으로도 갈립니다**(~700KB vs ~945KB). 제한 페이지는 본문·댓글이 안 실려서 250KB 작습니다.
문자열 마커와 크기 임계를 **둘 다** 쓰면 HTML 구조 변경에도 한쪽이 버팁니다.

⚠️ **일반 브라우저 UA 로는 안 됩니다.** 그 경우 인스타가 모든 페이지에 동일한 SPA 셸(639,8xx bytes)만
주고 마커가 JS 번들에 항상 존재해 구별 불가입니다. 실제로 이 방법으로 한 번 오판했습니다.
크롤러 UA(Googlebot)여야 SSR 본문이 옵니다. `facebookexternalhit` 는 og 태그만 주고 마커가 없어 **부적합**.

### 7-2. 붙일 자리 제안

| 지점 | 동작 |
|---|---|
| **캠페인 생성 API** | 대상 media 의 permalink 로 1회 검사 → 제한이면 **생성 차단 + 사유 안내**(2장 문구 재사용) |
| **캠페인 복사** | 동일. 지금은 죽은 게시물에 복사가 그냥 됩니다 (실측: 이걸로 42건 추가 실패) |
| **주기 스위퍼** | active 캠페인의 media 를 하루 1회 검사 → 제한 전환 감지 시 자동 정지 + 알림 |
| **어드민 상세** | 캠페인 화면에 "게시물 제한 여부" 뱃지 + 재검사 버튼 |

**구현 주의**
- 결과를 캐시할 것(media 당 최소 1시간). 같은 게시물을 반복 조회하지 말 것
- 실패(타임아웃·429·구조 변경)는 **fail-open** — 검사 실패로 캠페인 생성을 막으면 안 됨
- 크롤러 UA 사용은 공개 페이지 1회 조회 수준으로 제한. 대량 크롤링 금지
- 마커 문자열은 상수 1곳(`ig_content_restriction.py` 등)에 두고 테스트로 고정
- **정상 판정을 "영원히 정상"으로 캐시하지 말 것** — 실측상 게시 18분 뒤에 제한으로 바뀐 사례가 있습니다
