## 2. 부탁 2 — 결제 전 고지 기록(`PaymentConsent`)

**이 변경과 무관합니다. 설명드립니다.**

`PaymentConsent` 가 저장하는 날짜는 `disclosed_first_charge_at` — **첫 결제일**이고,
`trial_last_day` 가 아닙니다. 첫 결제일은 `trial_ends_at` 그대로라 이번에 바뀌지 않았습니다.

| 값 | 전 | 후 |
|---|---|---|
| `trial_ends_at` / `first_charge_at` | 2026-10-14 14:06 | **그대로** |
| `disclosed_first_charge_at` (동의 기록) | 2026-10-14 | **그대로** |
| `trial_last_day` (화면 "…까지 무료") | 2026-10-13 | **2026-10-14** |

즉 **동의 기록에 들어가는 값은 원래 맞았고**, 화면에 보여주던 "무료 종료일"만 하루 당겨져
있던 것입니다. 이제 둘이 같은 날짜가 됩니다 — 「10월 14일까지 무료 · 10월 14일 첫 결제」.

> 결제 화면에서 `disclosed_first_charge_at` 을 보내실 때 지금처럼 `first_charge_at` 기준으로
> 보내시면 됩니다. 바꾸실 것 없습니다.
