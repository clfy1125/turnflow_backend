## 1. 지금 바로 하실 수 있는 것

### `plans.features` 키가 내려갑니다

`GET /api/v1/billing/plans/` 응답에 들어갔습니다. 플랜 **이름**(`pro`/`admin`) 판정을
이 키로 바꿔 주세요.

```jsonc
// pro · admin
"dm_trigger_all_posts": true, "dm_trigger_next_media": true,
"dm_trigger_story_reply": true, "dm_follow_gate": true
// free · basic → 전부 false
```

### 403 응답

```jsonc
HTTP 403
{
  "detail": "'팔로우 확인 후 보상' 기능은 프로 요금제에서 사용할 수 있습니다.",
  "code": "PLAN_REQUIRED",
  "success": false,
  "error": {
    "code": 403,
    "message": "'팔로우 확인 후 보상' 기능은 프로 요금제에서 사용할 수 있습니다.",
    "details": { "code": "plan_required", "required_plan": "pro", "feature": "dm_follow_gate" }
  }
}
```

`details.feature` 로 **어느 기능에서 걸렸는지** 알 수 있습니다(요금제 창 문구를 기능별로).
`feature` 값은 `plans.features` 의 키와 같습니다.

## 3. ⏩ `scope` 운영 배포 — 지금 올려 주세요

unlink 를 기다리느라 미루고 계셨는데, **두 가지는 별개 문제**입니다(회신서 §2-2).

| | 해결하는 것 |
|---|---|
| `scope=...phone_number` | **기존 연결자 818명 + 신규**에게 전화번호 동의 화면 |
| unlink | **탈퇴했다가 다시 가입**하는 사람의 깨끗한 재동의 |

unlink 는 이제 끝났으니 **막는 것이 없습니다.**

이건 **사용자가 로그인할 때만** 받을 수 있습니다. 하루 늦으면 그날 로그인한 사람은
다음 로그인까지 기다려야 합니다. 지금 카카오 연결 **818명 중 번호 보유 40명**이고,
카카오로 받으면 **SMS 비용 0 · 사용자 입력 0회 · `/signup/phone` 자동 스킵**입니다.

검증은 **전화번호 동의 이력이 없는 카카오 계정**으로 dev 로그인 → 「카카오계정(전화번호)
(선택)」이 뜨는지 확인 → 뜨면 바로 운영.
