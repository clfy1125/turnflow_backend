# TurnFlow — 사업·제품 개요 (백엔드 기준)

> 작성일: 2026-08-18
> 대상 독자: **TurnFlow를 처음 접하는 사람** (경영진·투자자·평가기관·신규 합류자)
> 범위: **백엔드 저장소(`turnflow_backend`) 기준**. 프론트엔드/어드민 콘솔의 화면·UX는 별도 자료.
> 근거: 이 저장소의 실제 소스코드·마이그레이션·운영 설정. 추정치와 미구현 항목은 §9에 따로 명시.

---

## 1. 한 문장으로

**TurnFlow는 인스타그램으로 장사하는 사람의 "댓글 → DM → 판매 페이지 → 성과 측정"을
자동으로 굴려주는 국내 SaaS입니다.**

인스타그램에서 물건을 팔거나 예약을 받는 사람(공동구매 셀러, 소상공인, 강사, 인플루언서)은
매일 이 일을 손으로 합니다.

1. 게시물에 "링크요", "구매" 같은 댓글이 수십~수백 개 달린다
2. 한 명 한 명에게 DM으로 링크를 보낸다
3. 그 링크는 보통 인스타 프로필에 걸어둔 "링크 모음 페이지"다
4. 몇 명이 봤고 몇 명이 샀는지는 감으로 안다

TurnFlow는 **1~4번 전체를 하나의 서비스로 자동화**합니다.
댓글이 달리는 순간 감지해서, 정해둔 문구로 DM을 보내고, 그 DM 안의 링크 페이지까지
우리가 만들어주고, 몇 명에게 갔고 몇 명이 읽었는지를 숫자로 보여줍니다.

```
인스타 게시물 댓글  →  키워드 감지  →  자동 DM 발송  →  바이오링크 페이지(구매·신청)  →  통계
└──────────────────── 하나의 서비스, 하나의 구독료 ────────────────────┘
```

## 2. 왜 이 사업인가 — 시장의 구조적 빈틈

이 퍼널을 **통째로** 제공하는 국내 사업자가 사실상 없습니다. 경쟁 구도는 반으로 쪼개져 있습니다.

| 구분 | 대표 사업자 | 하는 일 | 못 하는 일 |
|---|---|---|---|
| 링크 페이지 | Linktree, 인포크링크, 리틀리 | 프로필 링크 모음 페이지 | **DM 자동화 없음** |
| DM 자동화 | ManyChat, 국내 DM 툴 | 댓글 → DM 발송 | **판매 페이지 없음/빈약** |
| **TurnFlow** | — | **양쪽 모두 + AI + 성과 측정** | — |

고객은 지금 **두 개를 따로 구독하고, 따로 연동하고, 성과는 합쳐 보지도 못합니다.**
TurnFlow는 그 둘을 한 청구서로 묶고, 데이터가 한 곳에 모이므로 "댓글 100개 → DM 92명 도달 →
페이지 61명 방문 → 클릭 23"처럼 **퍼널 전 구간을 하나의 숫자로** 보여줄 수 있습니다.

### 진입 장벽을 낮추는 두 개의 무기

1. **경쟁사 페이지 임포트** — Linktree·인포크링크·리틀리 URL을 붙여넣으면 블록 단위로 그대로 이주.
2. **경쟁사 DM 캠페인 이전** — 매니챗 등 다른 툴로 돌리던 자동 DM 캠페인을, 인스타 계정을 연동하기만
   하면 **우리가 역으로 분석해서 복원**합니다 (§4.3). 고객이 손으로 다시 세팅할 필요가 없습니다.

경쟁사 락인(갈아타기 비용)을 제품 기능으로 무력화하는 것이 획득 전략의 핵심입니다.

## 3. 누가 돈을 내는가 — 수익 모델

**월 구독(정액제)** 입니다. 결제는 토스페이먼츠 빌링키 기반 자동결제(원화).

| 플랜 | 월 가격 | 자동 DM | 페이지 | AI 생성 | 주요 포함 |
|---|---:|---|---:|---|---|
| **무료** | ₩0 | 200건/월 | 1개 | 가입 시 2회 | 커스텀 CSS, 기본 통계 |
| **베이직** | ₩4,900 | 200건/월 | 5개 | 무제한 | TurnFlow 배지 제거, 분석 내려받기 |
| **프로** ⭐ | ₩14,900 | **무제한** | 5개 | 무제한 | 스팸 필터, 실패 DM 복구, **인스타 성장 리포트**(IG 계정당 월 1회), 다계정 |

- **추가 인스타 계정**: 프로 기준 계정당 **+₩9,900/월**
- **무료 체험**: 프로는 카드 등록 시 **30일 무료** (제휴/레퍼럴 코드 사용 시 +30일, 1인 1회)
- **가격 스냅샷(그랜드파더링)**: 가입 시점 가격을 구독에 고정 저장 → 이후 정가를 올려도 기존 고객은 그대로
- **커머스 수수료 0%** (Linktree는 거래마다 9~12% 수취)

수익 구조상의 특징:

- **ManyChat은 "활성 컨택트 수" 종량제**라 캠페인이 성공할수록 고객 청구액이 계단식으로 오릅니다.
  TurnFlow 프로는 **정액 무제한**이라 고객 입장에서 비용이 예측 가능하고, 우리 입장에서는
  발송량이 늘어도 한계비용이 인프라 비용뿐입니다.
- 요금제·기능 한도는 코드가 아니라 **DB(`SubscriptionPlan.features`)에 저장**되어 있어,
  배포 없이 운영에서 가격·한도를 조정할 수 있습니다.

### 결제 파이프라인은 우리가 소유합니다

토스페이먼츠는 "빌링키로 승인해달라"는 요청만 처리하고, **정기결제 스케줄러가 없습니다.**
즉 *언제 누구에게 얼마를 청구할지*는 전적으로 우리 백엔드(Celery)가 결정합니다.

- 10분마다 갱신 도래 구독을 찾아 과금 (`process_due_renewals`)
- 30분마다 결과가 모호한 결제를 확정 (`reconcile_pending_payments`)
- 매시간 파이프라인 고장 감시 (`check_missed_payments`) — *결제 누락은 곧 매출 누락*
- 체험 만료·유예기간 만료·해지 만료·일시정지 만료 자동 처리
- 매일 구독 상태/MRR/결제 코호트 스냅샷 적재 (유지·해지 분석용)

중복 과금 방지는 3중으로 걸려 있고, 빌링키는 암호화 저장 + 로그 마스킹 처리됩니다.

## 4. 제품 — 백엔드가 실제로 하는 일

### 4.1 인스타그램 계정 연동

- Meta Graph API OAuth 연동, 토큰은 **암호화 저장**(평문 저장·로깅 금지)
- 댓글/DM 웹훅 구독 및 검증(HMAC), 구독이 Meta 쪽에서 자동 해제되면 **자동 재구독**
- 연결 상태 종합 진단 API(토큰 유효성·웹훅 구독 여부·만료 임박)
- **하나의 인스타 계정 = 하나의 워크스페이스** 원칙 (계정 도용·중복 자동화 차단)
- 웹훅 누락 대비: 시간당 폴링 보정 + 처리 이력 장부(`SeenComment`)로 빠진 댓글을 되잡음

### 4.2 자동 DM 엔진 — 제품의 심장

**트리거**: 특정 게시물 / 모든 게시물 / 앞으로 올릴 게시물 자동 부착 / 스토리 답장
**키워드 매칭**: 포함(ANY) · 전부 포함(ALL) · 완전 일치(EXACT) · 무조건

핵심 차별점은 기능 개수가 아니라 **"보냈다고 표시됐는데 실제로 안 간" 사고를 구조적으로 없앤 것**입니다.

| 장치 | 하는 일 |
|---|---|
| 상태머신 | `QUEUED → SUBMITTING → ACCEPTED → DELIVERED → READ` 단계별 추적 |
| 도착 이중 확인 | echo 웹훅 매칭 + Conversations API 능동 조회 |
| 멱등성 | `idempotency_key`(sha256) + `EventInbox` 장부 → 웹훅 재전송·재시도에도 중복 발송 0 |
| 실패 명시 분류 | 토큰만료 / 24h창 만료 / 파라미터 / 레이트리밋 / 흔적없음 — Meta 에러코드를 **사용자가 할 수 있는 행동**으로 번역 |
| 24시간 정책 검증 | Meta의 메시징 정책(최근 상호작용 24h 내) 위반 발송을 사전 차단 |
| 안전속도 거버너 | 계정 단위 분당/시간당 발송 상한 + 지터 → **인스타 계정 정지 리스크 방어** |
| 실패 DM 복구 | 확정 실패 건에 대해 재댓글 유도 → 정상 경로로 재발송(프로 전용) |
| 팔로우 게이트 | "팔로우했어요" 버튼 → 팔로우 여부 검증 → 보상 DM |
| 예약 캠페인 | 시작·종료 시각 지정, 종료 시 자동 종료(1분 주기 배치) |
| 소급 발송 | 캠페인을 켜기 전에 달린 과거 댓글에도 발송 가능 |

경쟁 국내 툴 대비로는 **이 발송 신뢰성 엔진 자체가 격차**이고, ManyChat 대비로는 가격 예측성과
바이오링크 통합이 격차입니다.

### 4.3 DM 캠페인 이전 — 경쟁사에서 뺏어오는 기능

고객이 매니챗·인포크링크 등에서 돌리던 자동 DM 캠페인을, **인스타 계정 연동만으로 복원**합니다.

동작: 최근 게시물·댓글·발신 DM 기록(Conversations API)을 수집 → 어떤 게시물의 어떤 키워드에
어떤 문구가 나갔는지를 역추론 → **비활성 초안 캠페인**으로 생성 → 고객은 검수 후 켜기만 하면 됩니다.

제품 원칙이 명확히 정해져 있습니다 — **"하나도 빠짐없이 이전시킨다. 시간이 더 걸려도 좋다."**
회수율(찾아낸 캠페인 수)이 속도·비용보다 우선하며, 확신이 낮은 후보는 버리지 않고
`검수 필요` 등급으로 내려 사용자가 판단하게 합니다. 실측 데이터에 근거해 탐색 깊이를
계속 늘려온 영역이고(댓글 축·대화 축 양쪽 소진), 비싼 조사 결과는 캐시에 재사용해 호출 비용을 억제합니다.

### 4.4 바이오링크 페이지 (판매 랜딩)

DM으로 보낸 링크가 도착하는 곳입니다. 즉 **DM 자동화의 전환 지점**이자 단독 상품이기도 합니다.

- **블록 15종 이상**: 프로필·링크·그룹링크·갤러리·영상·지도·문의폼·일정·폴더·공지 등
- **AI 페이지 생성**: 컨셉 한 줄 → 완성형 페이지. **12개 업종 레시피**(명함·랜딩·포트폴리오·
  공동구매·모바일 청첩장·제휴마케팅·커미션 등 국내 특화 포함)
- **AI 리뉴얼**: 기존 콘텐츠는 보존하고 색·폰트·구조만 개선
- **디자인 품질 보증**: AI가 자주 뽑는 촌스러운 색 제거, 배경/카드 명도차 보정,
  글자 대비 WCAG AA(4.5:1) **코드로 강제** — 모델이 못 지키는 규칙을 우리가 지킵니다
- **비전 비평 루프**: 렌더된 화면을 비전 LLM이 4축으로 채점하고 CSS를 패치
- **경쟁사 임포트**: Linktree·인포크링크·리틀리 URL → 블록 단위 변환
- **한국 커머스 메타 스크랩**: 쿠팡 파트너스·스마트스토어·오늘의집·네이버쇼핑 링크의
  제목·이미지·가격 자동 추출
- **통계**: 조회수·클릭수·유입 채널·국가 분포, 블록별/링크별 클릭
- **편집 이력**: AI 편집마다 스냅샷 자동 저장, 임의 시점 롤백
- **이미지 파이프라인**: HEIC 변환, EXIF/GPS 제거(개인정보), 해상도 상한, 자사 스토리지 재호스팅

### 4.5 인스타 성장 리포트 (프로 전용)

인스타 계정의 공개 데이터를 수집·분석해 **자기완결형 HTML 리포트 1파일**을 생성합니다.
계정당 월 1회, 생성에 평균 15분가량 걸리는 무거운 파이프라인입니다.

수집 → 지표 산출 → 표본 추출 → 영상 피처 분석(Gemini) → 집계 → 문장 합성(DeepSeek) → 검증 → 렌더.
전용 워커 큐로 분리되어 있어 다른 사용자의 실시간 DM 발송을 방해하지 않습니다.

### 4.6 스팸 필터 / 댓글 관리

부적절 댓글·경쟁사 홍보·도배를 자동 판별해 처리합니다(프로 전용).
자동 DM 트리거로 오인되는 것을 막는 역할도 겸합니다.

### 4.7 인사이트

인스타 게시물별 지표를 동기화해 성과를 조회·진단합니다.
(`/insights/` — 게시물 목록·상세·진단·집계·동기화 잡)

### 4.8 확장 채널 — TikTok / YouTube

인스타그램 외 채널로의 확장 축이 이미 코드에 존재합니다.

- **TikTok**: Business API 연동, 광고 댓글 수집, 스팸 필터, 금지어 관리
- **YouTube**: 채널 연동, 영상·댓글 수집, 스팸 필터

인스타에서 검증한 "댓글 수집 → 필터 → 자동화" 구조를 다른 플랫폼에 재사용하는 형태로,
멀티채널 SaaS로의 확장 경로가 아키텍처 수준에서 열려 있습니다.

### 4.9 백오피스 (어드민 API)

운영·마케팅을 데이터로 굴리기 위한 내부 관리 시스템입니다.

- 운영 대시보드(가입·구독·결제·체험 현황), 마케팅 대시보드(채널별 유입→가입→결제 퍼널)
- 회원/워크스페이스/페이지/자동 DM 모니터링, 레퍼럴 코드 관리
- **방문→가입 채널 귀속**: 랜딩 방문을 추적해 어떤 광고 채널이 실제 결제로 이어졌는지 계측
- UTM 링크를 서버에서 생성·관리(마케팅팀이 직접 만들지 않음 → 표기 오류로 인한 집계 실종 방지)
- 모든 관리자 행위는 감사 로그(`AdminActionLog`) 적재
- **역할 기반 접근제어(RBAC)** + 마케팅 전용 계정은 개인정보 자동 마스킹
- **관리자 2단계 인증(TOTP)** — 일반 로그인과 분리된 별도 관문

## 7. 아키텍처 원칙 — "왜 이렇게 만들었나"

평가 관점에서 의미 있는 것은 기능 목록보다 **운영 중 사고를 구조적으로 막는 설계**입니다.

1. **API-First** — 프론트 없이 Swagger만으로 전 기능 검증 가능. 프론트/백엔드 병렬 개발.
2. **멀티테넌시** — 모든 데이터를 워크스페이스(UUID) 단위로 논리 분리. 테넌트 간 데이터 누수 방지.
3. **비동기 처리** — 외부 API 의존 작업은 전부 Celery로. 사용자 요청이 외부 장애에 물리지 않음.
4. **멱등성** — 웹훅 재전송·재시도에도 중복 실행 0. 중복 DM·중복 과금이 발생할 수 없는 구조.
5. **관측성** — 요청마다 `X-Request-ID` 부여, 4xx/5xx 자동 로깅. 장애 추적이 가능.
6. **보안** — 외부 토큰·결제 키는 전부 암호화 저장, 로그 마스킹, 개인정보 최소 수집.
7. **정책 준수 내장** — Meta의 24시간 메시징 정책 검증을 발송 경로에 필수 통과 레이어로 배치.
8. **Mock 모드** — 플랫폼 승인 전에도 동일 로직으로 테스트 가능(개발 속도·리스크 분리).

## 8. 운영 성숙도

투자·평가 관점에서 "돌아가는 코드"와 "운영되는 서비스"를 가르는 지점들입니다.

- **프로덕션 가동 중** — 실사용자·실결제가 발생하는 상용 서비스
- **무중단 배포 절차 문서화** — DB 블립 0을 확보한 배포 시퀀스가 런북으로 확립
- **재해복구(DR)** — GCP cold-VM 기반 DR 환경 + 드릴 런북 (평상시 과금 0)
- **보안 감사 이력** — 취약점 감사 수행 및 하드닝 적용(SSH·Redis 인증·이미지 고정 등),
  침해 사고 대응 및 재발 방지 조치 이력 보유
- **개인정보 처리** — 타인의 DM/댓글 원문은 7일 자동 파기, 영구 캐시에는 판정 수치만 저장.
  이미지에서 EXIF/GPS 자동 제거. 개인정보처리방침·이용약관 법무 검토 자료 보유
- **결제 법규 대응** — 전자상거래법에 따른 결제 전 고지·동의 원장 구현
- **감사 추적** — 관리자 행위 전량 로깅
- **자동 배치 감시** — 결제 파이프라인 고장을 매시간 자체 감시(매출 누락 조기 탐지)

- 경쟁사 가격은 2026년 6월 공개 요금제 기준이며 변동됩니다. 최신값 확인 후 사용하세요.

## 10. 한 장 요약

> **TurnFlow는 인스타그램 댓글을 매출로 바꾸는 자동화 SaaS입니다.**
>
> 댓글 감지 → 자동 DM → 판매 페이지 → 성과 측정까지 퍼널 전체를 하나의 서비스로 제공하며,
> 국내 경쟁사는 이 퍼널의 절반씩만 갖고 있습니다.
> 경쟁사 페이지와 DM 캠페인을 **자동으로 이전**시켜 갈아타기 비용을 없애고,
> **월 14,900원 정액 무제한**으로 "성공할수록 비싸지는" 해외 툴의 종량제 구조와 정면 대비됩니다.
>
> 기술적으로는 165,000줄·72개 모델·92개 백그라운드 작업 규모의 상용 운영 시스템이며,
> 중복 발송·중복 과금·발송 누락을 **구조적으로** 차단하는 설계(멱등성·상태머신·이중 확인)와
> 결제·재해복구·보안·감사 추적까지 갖춘 운영 성숙도를 확보하고 있습니다.
> 인스타그램에서 검증한 구조는 TikTok·YouTube로 확장 중입니다.
